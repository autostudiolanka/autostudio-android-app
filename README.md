# AutoStudio Android App

STANDING RULES — put these in this project's Lovable knowledgeNo pricing, no currency symbol, no checkout, no purchase button, no external link to a pricing or billing page — anywhere. Signup and payment happen on the website. If a screen seems to need an upgrade call to action, leave it out and say so.

All colours, sizes and spacing come from CSS custom properties. Never write a hex value inline in a component. The token values will change.

Target width 390px. Design and check at that width.

Minimum touch target 44px. Extend the hit area with padding rather than growing the visual, where the two differ.

No hover states. Touch only. Use press feedback instead.

This app is consumption-only. No account creation, no dealership setup, no subscription changes. It signs in existing users and lets them manage stock and enquiries. Anything resembling onboarding belongs on the website.

Ask before adding a dependency.
